# Tagtokn — Black Mirror transcript and evidence edition

This repository replaces the previous marketplace/application surface with a transcript-first research site for Black Mirror closure axiometry, perspectival AGI, coevolution, native network tokenomics, and comparative loop-quantum-gravity / white-hole research.

## Causal order

1. Originless closure
2. Perspectival generation
3. Transformation
4. Independent return
5. Bounded evidence
6. Receipt and/or OPEN continuation

Formal models, hashes, ledgers, scores, prices, and test counts are downstream evidence or projections. They are not the origin of closure.

## Repository map

- `src/` — React research interface and small pure evidence functions.
- `documents/` — Version 5.0 transcript-first paper and Version 4.1 source-paper archive.
- `transcripts/` — direct quotation corpus and raw-archive availability note.
- `data/` — evidence ledger, tokenomics scenario, Xenobot measurements, and LQG/white-hole comparison.
- `research/` — artifact availability and reproducibility index.
- `tests/` — executable tests for the site’s finite return and tokenomic projections.

## Epistemic boundary

The site distinguishes transcript basis, rerunnable data, reported artifacts, published data, design translation, comparative literature, and OPEN boundaries. It does not claim a universal topology, unrestricted AGI, a proof of the Riemann hypothesis, a literal identity between closure and loop quantum gravity, or direct astrophysical evidence of white holes.

# Closure-native tokenomics

Tagtokn separates native semantic admission from market, ledger, and interface projections.

## Causal order

1. Originless closure is prior to a token, account, price, chain, or predefined topology.
2. A Potential Gate exposes an OPEN local/global perspective without issuing supply.
3. Human, AGI, and community pointings deform that gate.
4. An independent return discloses whether the relation is recoverable, contradictory, or still OPEN.
5. Only a recoverable non-self-authored return issues a semantic receipt.
6. A resolved relation may leave a residual child gate OPEN.

## Native token

A native token is a deterministic receipt of a resolved semantic topology. Its identity includes the gate, disclosed topology, and folded semantic history. It excludes timestamps, prices, cash values, and human-worth claims.

## Projection rules

- OPEN claims do not count as native supply.
- Circular internal volume does not create independent network integration.
- Price is a downstream basis projection: external support divided by displayed supply.
- User microactions remain folded in semantic history; the local ball need not enumerate its complete formal history.
- Closure value is a profile, not a scalar ranking of intelligence or persons.

## Current finite controls

The repository test suite checks OPEN admission, independent return, residual openings, contradiction, replay resistance, folded-history invariance, native supply, projection dilution, and non-scalar value profiles. Passing tests establish only the declared finite software behavior.
